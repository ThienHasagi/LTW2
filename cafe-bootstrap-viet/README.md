# Mộc Cafe - Website Bootstrap tĩnh

Project giao diện trang web quán cafe bằng tiếng Việt, chỉ dùng HTML, CSS và Bootstrap CDN.

## Cách mở trong Visual Studio Code

1. Mở VS Code.
2. Chọn `File > Open Workspace from File...`.
3. Chọn file `D:\cafe-bootstrap-viet\moc-cafe.code-workspace`.
4. Mở `index.html` bằng Live Server hoặc mở trực tiếp trong trình duyệt.

## Cấu trúc

- `index.html`: giao diện chính.
- `assets/css/styles.css`: CSS tùy chỉnh.
- `.vscode/settings.json`: cấu hình workspace cơ bản.
